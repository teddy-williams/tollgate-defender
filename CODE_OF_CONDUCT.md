# Code of conduct

This project is a place for defenders to work together. We expect everyone who takes part (issues, pull requests,
discussions, rule contributions) to:

- be respectful and assume good faith; critique ideas and code, not people
- welcome newcomers and answer questions patiently
- keep discussion on defensive security; no requests for help attacking systems you do not own or are not authorised to test
- never post live malware, stolen data, credentials, or personal information about others
- respect responsible disclosure: report vulnerabilities privately (see SECURITY.md)

Harassment, discrimination, threats and deliberately disruptive behaviour are not tolerated. Maintainers may edit or remove
contributions, lock threads, and block people who break these rules. To report a problem, contact williamsmavuso@gmail.com.
This statement is adapted in spirit from widely used community codes such as the Contributor Covenant.
